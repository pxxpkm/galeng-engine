# example-prologue

Hand-written fixture plus tiny placeholder PNGs, a 1.2s BGM loop (`assets/bgm/park.wav`), two short voice clips, and a breeze SE. Missing pictures fall back to color blocks. Missing audio is silence.

```
cargo run -p galeng-player -- --project examples/prologue
```

繁中劇本。選「一起走吧」進 `park_02`；選「該回去了」進 `home_01`。兩條都是結局。
