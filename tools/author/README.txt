Galeng editor
=============

English
-------
This folder is the author pack. You do not need Rust or pnpm.

1. Double-click Galeng.bat
2. A browser opens at http://127.0.0.1:3847  (not localhost)
3. Close the black window to stop the editor

Default project: examples\prologue

Your own project (a folder that contains galeng.json):
  - Drag that folder onto Galeng.bat
  - Or: Galeng.bat D:\MyGame

Play from here needs galeng-player.exe and SDL2.dll in this same folder.
Do not bind the host to 0.0.0.0. There is no login.

繁體中文
--------
這是作者包。不必裝 Rust，也不必裝 pnpm。

1. 雙擊 Galeng.bat
2. 瀏覽器開 http://127.0.0.1:3847（不要打 localhost）
3. 關掉黑色視窗＝關掉編輯器

預設專案：examples\prologue

自己的專案（資料夾裡要有 galeng.json）：
  - 把資料夾拖到 Galeng.bat
  - 或：Galeng.bat D:\MyGame

「從此處播放」需要同目錄的 galeng-player.exe 與 SDL2.dll。
不要把 host 綁到 0.0.0.0。沒有登入。
